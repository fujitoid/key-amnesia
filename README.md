# key-amnesia has moved and is now Vahta

**This repository is an archived signpost. It holds no code.**

### Where everything went

| | |
|---|---|
| Source, issues, releases, wiki | **https://github.com/vahta-team/vahta** |
| PyPI, unchanged and still installable | https://pypi.org/project/key-amnesia/ |

`key-amnesia` was renamed **Vahta** after the product and its concept were
tested, and rebuilt on a new core. The repository was renamed and transferred,
so its history, issues, releases and stars all live at the link above —
nothing was lost and nothing was restarted.

### If you already use key-amnesia

Nothing breaks. `pip install key-amnesia` keeps working, and the package will
**never be yanked**, so pinned installs are safe. One final release is planned
whose only change is to say what this page says.

### Why this empty repository exists

GitHub redirects an old repository URL to its new home — until someone creates
a repository under the freed name, at which point the redirect dies and that
name serves whatever they put there. For a tool that guards credentials, an
old URL that has been **taken over** is far worse than one that is merely
broken. So the name is held here deliberately, pointing where it should, and
archived so it can never be anything else.
